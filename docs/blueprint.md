# **App Name**: Morpheus, My Love

## Core Features:

- AI Chat Simulation: Simulate chat with Morpheus, an AI companion that responds like a loving girlfriend, adapting responses based on user input using a LLM.
- Interactive Chat UI: A chat interface with realistic message bubbles, timestamps, and a clear, intuitive layout.
- Relationship Customization: Personalized profile settings for customizing Morpheus's persona and relationship dynamics.
- Sentiment analysis and personalization: Tool for Sentiment Analysis: analyze user's messages and adapt the conversation accordingly.
- Privacy Management: Privacy controls to manage conversation history and data sharing.
- Personalization: Ability to generate or update a cover photo.

## Style Guidelines:

- Primary color: Soft rose (#F472B6) to evoke feelings of love and warmth.
- Background color: Light blush (#FCE4EC), a gentle, desaturated version of the primary color, providing a calming backdrop.
- Accent color: Lavender (#D8B4FE), an analogous color, adding a touch of enchantment and whimsy for interactive elements.
- Body and headline font: 'Alegreya', a serif font, for an elegant and intellectual feel.
- Delicate, custom icons in the accent color for key actions.
- Clean, conversational layout with clear visual hierarchy.
- Gentle transitions and subtle animations when receiving new messages.
